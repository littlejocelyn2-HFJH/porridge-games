## 安全設計（這次的重點）

- **答案不在 GitHub 上。** 答案、段落提示、前測層級都在老師另外拿到的 `Answers.gs`，只貼在老師自己的 Apps Script 裡。批改由後端完成。
- 學生文字寫進試算表前會先處理，不會被當成公式。
- 班級要三位數、座號 1～60；同一座號 60 秒內只能開始一次新練習。
- 老師密碼錯一次延遲 2 秒；10 分鐘內錯 10 次，暫停登入 10 分鐘。
- 老師頁可刪除單次練習紀錄（處理冒名或測試資料）。

## 部署步驟

1. **GitHub Pages**：repo → Settings → Pages → Deploy from a branch → main / (root)。
2. **Google 試算表**：新增一份（例如「以粥養生閱讀小誌」）→ 擴充功能 → Apps Script：
   - 把 `apps-script/Code.gs` 全部貼進 `程式碼.gs`，第 8 行密碼改掉（10 字以上、英文夾數字）。
   - 左邊「檔案」旁按 ＋ → 指令碼，命名 `Answers`，貼上老師拿到的 `Answers.gs`（**不在 GitHub 上**）。
   - 存檔 → 部署 → 新增部署作業 → 網頁應用程式｜執行身分：我｜存取權：所有人 → 部署、授權。
   - 把 `/exec` 網址交給 Claude 填進 `config.js`。
3. 直接開 `/exec` 網址看到 `{"ok":true,..."answers":true}` 代表 Answers.gs 也貼好了。

## 以後改題目（不用再進 Apps Script）

後端是**通用版**：只負責批改（分類、排序、填空、參考筆記四種題型）和儲存，不寫死任何一關。

- **改答案、提示、參考筆記**：Claude 會給一段 `PZA1:` 開頭的代碼 → 老師頁「教師區 → 更新答案」貼上 → 按「更新答案」。立即生效，不用重新部署。目前版本會顯示在同一個框上方。
- **改網頁上的題目文字、紙片**：Claude 改 GitHub 上的檔案就好，老師不用做事。
- **只有加入全新的題型或功能**時，才需要更新 `Code.gs`：重新貼上 → 再改一次密碼 → 部署 → 管理部署作業 → 編輯 → 版本選「新版本」。網址不變。
